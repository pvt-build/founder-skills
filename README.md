# FounderOS · Arsenal de skills

**by PrivateBuild™**

Skills que instalas en Claude para operar tu negocio sin depender de que
alguien las ejecute por ti.

Cada una hace una cosa: sabe qué preguntar, en qué orden mirar los números,
y qué decisión devolver. No son plantillas — son criterio empaquetado.

---

## Qué es Private Build

Private Build es un hub para emprendedores digitales que venden servicios o
productos high ticket por internet. Cuenta con programas de consultoría,
coaching y equity para founders early & mid stage.

Acá encontrarás el repositorio de skills para descargar, las cuales son
actualizadas cada semana.

## Cómo se instalan

1. Descarga la carpeta `skills/`.
2. En Claude, ve a **Configuración → Capacidades → Skills**.
3. Sube cada carpeta de skill.
4. Claude las activa solas cuando la conversación lo amerita — no hace falta
   llamarlas por nombre.

También funcionan copiando el contenido de un `SKILL.md` directo en el chat
cuando necesitas esa lógica una sola vez.

---

## Tres reglas que atraviesan todas

**Un cuello a la vez.** Mejorar algo que no es el cuello actual no cambia el
resultado. Se siente productivo y no mueve el número.

**El dato antes que la decisión.** Si la atribución está sucia o las cuotas
se cuentan como ventas nuevas, cualquier decisión sobre esos números está
mal tomada. Primero se limpia.

**El ingreso del mes es la cifra más ruidosa.** Sirve para el titular. Las
decisiones se toman sobre tasa de cierre y Add-to-Cart, que se mueven
despacio y dicen la verdad.

## ¿Y si prefieres no operarlas solo?

Las skills te dan el criterio. Si prefieres que alguien las corra contigo —
o directo por ti — Private Build tiene tres puertas, según cuánto tiempo
tienes y cuánto quieres delegar:

| Puerta | Para quién |
|---|---|
| **Consultoría** | Quieres el criterio, tú ejecutas — sesiones 1:1 sobre tu negocio real |
| **Coaching** | Quieres acompañamiento sostenido mientras escalas, no una sesión suelta |
| **Equity** | Quieres que Private Build se juegue contigo, no solo te asesore |

Si algo de esto te resuena, escríbele a Patricio — el founder detrás de
Private Build acompaña personalmente a los founders que entran por acá.
