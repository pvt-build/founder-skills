# Growth Engine

## Para qué sirve

Un negocio siempre tiene un solo cuello a la vez. Mejorar cualquier cosa que
no sea ese cuello **no cambia el resultado** — se siente productivo y no
mueve el número.

Esta skill existe para encontrar ese cuello y proteger el foco.

## Cómo se encuentra el cuello

Se recorre el embudo completo y se busca **el peor salto**, no el número más
feo:

```
tráfico → conversación → cita agendada → asistencia → cierre → recompra
```

En cada tramo: de 100 que entran, ¿cuántos pasan al siguiente? El cuello es
el tramo donde más se cae, no el que más molesta.

## La regla dura

**Se trabaja un cuello a la vez.** Cuando se destapa, aparece otro — y eso
no es fracaso, es cómo funciona. El negocio siempre va a tener un cuello
nuevo; la tarea es encontrarlo, no evitarlo.

## Negocio de dos canales

Cuando hay tienda física y web, no comparten cuello y **no se comparan
entre sí**. Cada uno tiene su métrica y su leverage:

| | Métrica que manda | Leverage |
|---|---|---|
| Tienda | Tasa de cierre | Horas de equipo |
| Web | Add-to-Cart | Ninguna hora |

Un canal que crece consumiendo horas tiene techo. Uno que crece sin
consumirlas, no. Eso decide dónde poner el esfuerzo cuando los dos van bien.

## Qué skill toca según el cuello

| Si el cuello está en... | Abre |
|---|---|
| No llega gente | `paid-media` o `seo` |
| Llegan pero no agendan | `paid-media` (mix de público) |
| Agendan y no llegan | Ventana de agendamiento y recordatorios |
| Llegan y no compran | `cro` si es web · guion de cierre si es tienda |
| Compran una vez y no vuelven | `email-marketing` |
| No sé qué está pasando | `reporting` primero |

## Antes de abrir un frente nuevo

Tres preguntas:

1. ¿Esto ataca el cuello actual, o es un frente paralelo?
2. ¿Se puede medir en dos semanas?
3. Si funciona, ¿cambia el número del mes o solo se siente bien?

Si alguna respuesta es no, no se abre todavía.

## Lo que devuelve

El cuello nombrado con el dato que lo prueba, la skill que lo trabaja, y qué
se mide para saber si se destapó.
